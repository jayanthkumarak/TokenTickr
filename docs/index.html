The Value Proposition

Why TokenTickr Exists

Users come to TokenTickr to answer one question:

"If I use this cheaper model instead of the frontier model, how much intelligence am I giving up for how much cost savings?"

TokenTickr quantifies this tradeoff, helping teams find "good deal" models that deliver 70-90% of frontier intelligence at significantly lower cost.

Key Insights

  • Intelligence is the X-factor — its value is non-linear and hard to quantify
  • Context enables intelligence — a genius model with 4K context is useless for complex tasks
  • Price tolerance scales with consequence — mission-critical tasks justify premium pricing

Smart Score Formula

The Smart Score uses dynamic tier-based weighting with a context gate. Unlike simple weighted averages, the formula adapts based on how close a model is to the current state-of-the-art. 

function calculateSmartScore(perf, price, ctx, allModels) {
  // 1. Dynamic tier threshold (relative to current max)
  const maxPerf = Math.max(...allModels.map(m => m.perfScore));
  
  // 2. Context gate: models with <64K context are penalized
  const contextGate = ctx >= 50 ? 1.0 : 0.5 + (ctx / 100);
  
  // 3. Dynamic weights based on relative position
  const ratio = perf / maxPerf;
  let weights;
  
  if (ratio >= 0.90) {
    weights = { intel: 0.60, context: 0.35, price: 0.05 };  // FRONTIER
  } else if (ratio >= 0.70) {
    weights = { intel: 0.50, context: 0.30, price: 0.20 };  // PRO
  } else {
    weights = { intel: 0.35, context: 0.25, price: 0.40 };  // BUDGET
  }
  
  // 4. Weighted score with gate
  const raw = (weights.intel * perf) + (weights.context * ctx) + (weights.price * price);
  return contextGate * raw;
}

Why This Approach?

  • Future-proof — thresholds adjust automatically as models improve
  • Context gate — ensures intelligence without capacity doesn't dominate
  • Tier-appropriate pricing — frontier users don't care about price; budget users do

Dynamic Tier System

Models are classified into tiers based on their performance relative to the best model currently being compared. This ensures the scoring stays relevant as the model landscape evolves.

"The deals zone — tradeoff land"

Data Sources

TokenTickr uses a cascading data quality system for performance scores, clearly labeled in the UI.

🔵 AA Intelligence Index (361 models)

Primary source from Artificial Analysis. A composite benchmark aggregating MMLU-Pro, LiveBench, AIME 2024/2025, GPQA Diamond, and IFBench.

  • Confidence: High — objective, multi-source composite
  • Coverage: 361 models auto-generated from API
  • UI Badge: Blue "AA Index"

🟢 LMSYS Verified (Fallback)

Human preference ratings from LMSYS Chatbot Arena. Uses anonymous pairwise comparisons with 1M+ human evaluations.

  • Confidence: High — crowdsourced blind testing
  • UI Badge: Green "Verified"

🟣 Heuristic (Last Resort)

Algorithmic calculation based on parameter count, model family, and context length. Conservative ceiling of 1280 Elo to avoid overestimating unknown models.

  • Confidence: Low — rough approximation
  • UI Badge: Purple "Heuristic"
