Documentation

TokenTickr is a next-generation LLM model comparison tool. It moves beyond simple price checking to provide a holistic Value Score based on three pillars: Price, Intelligence (Elo), and Context Capacity.

The "Balanced Trinity" Scoring

Unlike v1 which heavily favored price, v2 introduces a balanced weighting system to identify truly high-value models.

Interactive Calculator

Adjust the sub-scores to see how the final Value Score is calculated using the 37.5/37.5/25 formula.

Price Score (37.5%) 80
Performance/Elo (37.5%) 90
Context Length (25%) 70
Value Score: 80.0

Logic Breakdown

const valueScore =
  (0.375 * priceScore) +
  (0.375 * perfScore) +
  (0.25 * contextScore);

Context Fallbacks: For models reporting 0 context (e.g. Opus 4.5), we use a fallback map src/lib/static-eval-map.ts to ensure fair scoring.

Core Components

SmartValueRanking

src/components/smart-value-ranking.tsx

Displays the top-ranked model card. Features:

  • Value Score Badge (0-100)
  • Elo Source Indicator ("Verified" vs "Est.")
  • Animated progress bars for the 3 sub-metrics.

ContextComparisonChart

src/components/context-comparison-chart.tsx

A VisX-powered bar chart comparing context windows. Includes "Witty Analogies" (e.g., "1 Novel", "Entire Wikipedia") that dynamically position inside or outside bars based on width.

Deployment & Verification

Testing

We use Vitest for unit testing core logic. Always run tests before pushing.

Deploying to Production

The project is deployed via Cloudflare Pages. Deployment is triggered automatically via Git.

  1. Commit changes to tokentickr_v2 (feature branch).
  2. Merge Pull Request to main.
  3. Cloudflare detects the push to main and builds.
Troubleshooting: If a build fails, check for unused variables. The CI treats warnings as errors.
